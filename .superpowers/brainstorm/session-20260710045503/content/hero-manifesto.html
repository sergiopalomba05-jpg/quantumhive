Reglas de esta dirección
1. El video no va como fondo eterno. Tu intro se usa como apertura premium del hero o como modal de lanzamiento, no como wallpaper continuo que distrae.
2. El claim abre visión de empresa. Primero marca-madre y nueva categoría de inteligencia; después baja a capacidades concretas.
3. Negro + dorado como base. Azul eléctrico solo como energía secundaria, nunca dominando la marca.
4. Mucho vacío, poco ruido. Se tiene que sentir grande, tecnológica y cara. No una web saturada de cards genéricas.
5. Lo humano aparece como consecuencia. Los avatares y la voz están, pero dentro de una narrativa de infraestructura superior, no como gimmick aislado.

Lo que gana esta versión

  • Posicionamiento de empresa grande y global
  • Más memorabilidad de marca
  • Mejor encaje con el intro real y el isotipo

Riesgo a controlar

  • Puede volverse abstracta si no bajamos rápido a capacidades reales
  • Necesita copy muy preciso y pocas palabras
  • La demo tiene que aparecer pronto para validar credibilidad
